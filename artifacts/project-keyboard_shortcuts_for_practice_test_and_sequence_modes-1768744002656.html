Keyboard Shortcuts

Global (Dashboard):
- Ctrl/Cmd + K: Focus search
- Ctrl/Cmd + N: New deck
- Ctrl/Cmd + ,: Open settings
Learn Mode:
- Space / Enter: Show answer (flashcards)
- Enter: Check answer (typed); if empty, mark “Don’t know”
- 1 / ←: Incorrect
- 2 / →: Correct
Review & Exam Modes:
- Space / Enter: Show answer (flashcards)
- Enter: Check answer (typed)
- 1 / ←: Incorrect
- 2 / →: Correct
Practice Test Mode:
- Enter / ↑ / Space: Show answer / Check answer / Next (contextual)
- 1 / ←: Incorrect
- 2 / →: Correct
Sequence Mode:
- Enter / Space: Submit task
- Enter / Space: Continue (after feedback)
Editor:
- Ctrl/Cmd + S: Save deck
- Ctrl/Cmd + Enter: Add card/sequence

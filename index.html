Keyboard Shortcuts

Global (Dashboard):
- Ctrl/Cmd + K: Focus search
- Ctrl/Cmd + N: New deck
- Ctrl/Cmd + ,: Open settings
Learn Mode:
- Space / Enter: Show answer (flashcards)
- Enter: Check answer (typed); if empty, mark “Don’t know”
- 1 / ←: Incorrect
- 2 / →: Correct
Review and Legacy Exam Modes:
- Space / Enter: Show answer (flashcards)
- Enter: Check answer (typed)
- 1 / Left arrow: Incorrect
- 2 / Right arrow: Correct
Practice Test Mode:
- Enter / Up arrow / Space: Show answer / Check answer / Next (contextual)
- 1 / Left arrow: Incorrect
- 2 / Right arrow: Correct
Sequence Mode:
- Enter / Space: Submit task
- Enter / Space: Continue (after feedback)
Exam Mode:
- S: Start optimal session (Hub)
- T: Browse topics (Hub)
- Left / Right arrows: Previous / Next question
- 1-4: Select MCQ option
- Enter: Submit answer
- F: Flag question for review
- E: Show explanation
- H: Show hint
- Escape: Pause session
- Ctrl/Cmd + S: Submit exam
Editor:
- Ctrl/Cmd + S: Save deck
- Ctrl/Cmd + Enter: Add card/sequence
